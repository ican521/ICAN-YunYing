# 目录结构说明

## 顶层结构
```
D:\new tvbox\
├── app/                    # Android 应用模块
├── docs/                   # 项目规范文档
├── build.gradle.kts         # 项目构建配置
├── settings.gradle.kts      # 模块引入配置
└── gradle.properties        # Gradle 属性
```

## app/src/main/ 结构
```
app/src/main/
├── AndroidManifest.xml      # 清单文件
├── assets/                  # 静态资源（证书等）
├── java/com/ican/tvplay/    # 源代码
│   ├── MainActivity.kt      # 主 Activity
│   ├── data/                 # 数据层
│   │   ├── SettingsRepository.kt  # 设置存储
│   │   └── ...
│   ├── player/              # 播放器模块
│   │   ├── PlayerScreen.kt   # 播放页 UI
│   │   └── core/             # 播放器核心逻辑
│   ├── collection/          # 收藏/历史模块
│   │   └── CollectionScreens.kt
│   ├── settings/             # 设置模块
│   │   ├── SettingsScreen.kt
│   │   └── ColorPaletteScreen.kt
│   ├── ui/                   # UI 通用组件
│   │   ├── home/            # 首页
│   │   │   └── HomeScreen.kt
│   │   ├── search/          # 搜索页
│   │   ├── components/      # 通用组件
│   │   └── theme/           # 主题
│   └── ...
```

## 关键模块职责

| 模块 | 职责 |
|------|------|
| `player/` | 视频播放、播放控制、画中画、错误处理 |
| `collection/` | 收藏列表、播放历史 |
| `settings/` | 设置页、主题色板 |
| `ui/home/` | 首页（分类 Tab + 视频网格） |
| `ui/search/` | 搜索页、多站源搜索 |
| `ui/components/` | 通用组件（顶栏、底栏、按钮等） |
| `data/` | 数据存储、设置持久化 |
| `ui/theme/` | 颜色、字号、间距定义 |

## 资源文件

```
app/src/main/res/
├── drawable/               # 图标
├── values/                 # 字符串、颜色、样式
└── mipmap-*/              # APP 图标
```
