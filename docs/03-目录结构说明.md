# 目录结构说明

## 顶层结构
```
D:\new tvbox\
├── app/                    # Android 应用模块
├── docs/                   # 项目规范文档
├── gradle/
│   ├── wrapper/            # Gradle Wrapper
│   └── libs.versions.toml  # 依赖版本集中管理
├── build.gradle.kts         # 项目构建配置
├── settings.gradle.kts      # 模块引入配置
├── gradle.properties        # Gradle 属性
└── .gitignore               # 忽略规则（见 01「仓库清洁规范」）
```

## app/src/main/ 结构
```
app/src/main/
├── AndroidManifest.xml           # 清单文件
├── assets/                       # 静态资源（cacert.pem 证书等）
├── java/com/ican/tvplay/         # 源代码
│   ├── MainActivity.kt           # 主 Activity（兼画中画）
│   ├── TvPlayApplication.kt      # Application，初始化容器/播放器
│   ├── data/                     # 数据层
│   │   ├── local/                # 本地存储
│   │   ├── model/                # 数据模型
│   │   ├── remote/               # TvBox 接口、站源解析
│   │   └── SettingsRepository.kt # 设置存储
│   ├── player/                   # 播放器模块
│   │   ├── PlayerScreen.kt       # 播放页 UI / 全屏控制层
│   │   ├── core/                 # 播放核心、播放服务
│   │   └── cast/                 # 投屏
│   ├── collection/               # 收藏/历史模块
│   ├── settings/                 # 设置页、主题色板
│   ├── util/                     # 通用工具（PosterImages、ToastBlocker 等）
│   └── ui/
│       ├── AppRoot.kt            # 根 Composable、导航宿主
│       ├── home/                 # 首页
│       ├── search/               # 搜索页
│       ├── components/           # 通用组件（顶栏、底栏、按钮、间距）
│       ├── nav/                  # 路由定义与导航
│       └── theme/                # 颜色、字号、间距
└── res/
    ├── layout/player_view.xml    # 自绘 PlayerView 布局
    ├── drawable*/                # 图标
    ├── anim/                     # 动画资源
    ├── values/                   # 字符串、颜色、样式
    └── mipmap-*/                 # APP 图标
```

## 关键模块职责

| 模块 | 职责 |
|------|------|
| `player/` | 视频播放、播放控制、画中画、错误处理 |
| `collection/` | 收藏列表、播放历史 |
| `settings/` | 设置页、主题色板 |
| `ui/home/` | 首页（分类 Tab + 视频网格） |
| `ui/search/` | 搜索页、多站源搜索 |
| `ui/components/` | 通用组件（顶栏、底栏、按钮等） |
| `data/` | 数据存储、设置持久化、TvBox 接口与站源解析 |
| `ui/nav/` | 路由定义、导航栈管理 |
| `ui/theme/` | 颜色、字号、间距定义 |
| `util/` | 与环境无关的通用工具 |

## 关键资产

| 路径 | 说明 |
|------|------|
| `app/libs/*.aar` | 播放器/解码器依赖，构建脚本 `fileTree("libs") { include("*.aar") }` **只认 AAR**；禁止放 zip、解压目录、临时 jar |
| `app/release.keystore` | release 签名文件，本地保存、已被 `.gitignore` 忽略，**禁止提交** |
| `gradle/libs.versions.toml` | 依赖版本集中管理，升级依赖只改这里 |
| `app/src/main/res/layout/player_view.xml` | 自绘 PlayerView 布局（SurfaceView） |
| `app/src/main/assets/cacert.pem` | 网络请求根证书 |
