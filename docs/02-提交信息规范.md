# Git 提交信息规范

## 格式
```
类型: 简要描述
```

## 类型前缀

| 前缀 | 用途 | 示例 |
|------|------|------|
| `feat` | 新功能 | feat: 新增画中画自动切换站源 |
| `fix` | 修复 bug | fix: 修复快速切页时空白块闪烁 |
| `ui` | UI 调整 | ui: 顶栏统一为固定居中大标题 |
| `refactor` | 重构 | refactor: 抽取播放页控制栏组件 |
| `perf` | 性能优化 | perf: 优化网格滑动帧率 |
| `chore` | 杂项 | chore: 更新依赖版本 |

## 规则
1. **一句话说清做了什么**，不要写"修改了代码"、"调整了一下"
2. 描述用中文，简洁明了
3. 一次 commit 只做一件事，不要混合多个不相关改动
4. 标题不超过 50 字

## 示例
```
ui: 收藏/设置/历史/主题色板页顶栏统一为固定居中大标题
fix: 修复平板横屏预览小窗上滑回桌面不暂停
feat: 新增底部胶囊毛玻璃开关，与液态玻璃互斥
perf: 优化快速切页时 grid 同步性能
```

## 查看历史
```powershell
git log --oneline -10
```
