# Git 提交信息规范

## 格式
```
类型: 简要描述
```

## 类型前缀

| 前缀 | 用途 | 示例 |
|------|------|------|
| `feat` | 新功能 | feat: 新增画中画自动切换站源 |
| `fix` | 修复 bug | fix: 修复快速切页时空白块闪烁 |
| `ui` | UI 调整 | ui: 顶栏统一为固定居中大标题 |
| `refactor` | 重构 | refactor: 抽取播放页控制栏组件 |
| `perf` | 性能优化 | perf: 优化网格滑动帧率 |
| `chore` | 清理、依赖、配置等杂项 | chore: 清理无用解压产物并补充 .gitignore |
| `docs` | 仅文档改动 | docs: 新增仓库清洁规范 |
| `test` | 测试相关 | test: 补充播放进度单元测试 |

## 规则
1. **一句话说清做了什么**，不要写"修改了代码"、"调整了一下"
2. 描述用中文，简洁明了
3. 一次 commit 只做一件事，不要混合多个不相关改动
4. 标题不超过 50 字
5. **提交前必须编译通过**（纯文档改动除外）
6. **禁止提交 APK、截图、设计稿、UI dump 等本机文件**（见 [01-开发流程规范](01-开发流程规范.md) 的「仓库清洁规范」）
7. `main` 分支禁止 force push；需要重写历史必须先确认

## 示例
```
ui: 收藏/设置/历史/主题色板页顶栏统一为固定居中大标题
fix: 修复平板横屏预览小窗上滑回桌面不暂停
feat: 新增底部胶囊毛玻璃开关，与液态玻璃互斥
perf: 优化快速切页时 grid 同步性能
```

## 查看历史
```powershell
git log --oneline -10
```
