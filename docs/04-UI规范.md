# UI 规范

## 基准与优先级

- 本文档是所有 UI / 布局 / 间距 / 字号 / 颜色改动的**唯一基准**，任何改动前必须先读本文档。
- **样式优先以 miuix 官方组件为准**：miuix 官方文档 https://compose-miuix-ui.github.io/miuix/ （中文站 https://compose-miuix-ui.github.io/miuix/zh_CN/ ）。
- 新增页面或改动现有页面时，**优先复用 miuix 已有组件**（TopAppBar、BreadcrumbBar、Card、TextField、Switch、Button 等），样式、间距、动效直接对齐 miuix 默认值，不自造轮子。
- 当 miuix 样式与 KernelSU / fongmi 等其他参考实现冲突时，**miuix 优先**；仅当 miuix 不提供该组件或明确不适用于 TV 场景时，才回退到其他参考。
- 本项目当前使用 miuix 0.9.4，组件默认值以该版本为准。

## 间距基准

### 页面边距
| 名称 | 值 | 说明 |
|------|-----|------|
| 页面左右边距 | 16dp | 所有页面统一（手机/平板一致），统一调用 `pageHorizontalPadding()`；页面外边距禁止写死 dp，组件内部 padding 可用组件自身常量或合理 dp 值（如站源 chip 水平 16dp）
| 顶部状态栏 | 系统自动处理 | WindowInsets.statusBars |
| 顶栏顶部间距 | 14dp | pageTop |
| 底栏内边距 | 系统自动处理 | |

### 组件间距

以下数值统一来自 `Spacing.kt`，页面级间距禁止手写 dp；组件内部间距（chip 内边距等）可使用组件自身常量或合理的 dp 值：

| 名称 | 值 | 常量 |
|------|-----|------|
| 卡片水平间距 | 16dp | `Spacing.cardGapH` |
| 卡片垂直间距 | 16dp | `Spacing.cardGapV` |
| 大板块之间 | 20dp | `Spacing.sectionSpacing` |
| 板块标题与内容 | 12dp | `Spacing.titleContentGap` |
| 追番更新页板块卡片之间 | 20dp | `Spacing.sectionSpacing` |

## 顶栏规范

### 二级页顶栏（设置/收藏/历史/主题色板/追番更新）
- 高度：52dp（统一引用 `Spacing.centeredTopBarHeight`）
- 标题：居中，titleLarge，默认字重（不加粗）
- 返回键：左侧对齐 16dp，48dp 圆形按钮，图标 24dp（追番更新页、主题色板页、搜索页为无底色裸图标）
- 背景：毛玻璃（BlurredBar）

### 首页顶栏
- 搜索栏：48dp 高，居中
- 分类 Tab：固定在搜索栏下方
- 毛玻璃效果

### 搜索页顶栏（编辑态/结果态共用）
- 结构：状态栏 → 16dp → 搜索栏（48dp）→ 16dp → 顶栏底缘
- 下方内容紧贴顶栏底缘，不再另加顶部间距；滚动内容经滚动容器 `contentPadding.top` 进入顶栏后方
- 返回键：无底色裸图标（见上方二级页顶栏条目）

## 底栏规范
- 胶囊形，悬浮在底部
- 三个 tab：首页 / 收藏 / 设置
- 毛玻璃效果（与液态玻璃互斥）

## 字号规范
| 用途 | 字号 | 字重 |
|------|------|------|
| 页面大标题 | titleLarge (~22sp) | 默认字重（不加粗） |
| 卡片标题 | titleSmall | 默认字重 |
| 辅助文字 | bodyMedium | Regular |
| 小标签（评分角标等） | labelSmall | Regular |

> 例外：播放页内「视频标题 / 线路 / 选集 / 简介」四个标题保留 SemiBold，其余页面标题一律不加粗。
>
> 现状例外（允许保留裸 `fontSize`，不做强制收敛）：搜索栏占位文字 16sp、空状态 24sp / 18sp、底栏角标 11sp；新增代码仍应优先使用 `MaterialTheme.typography`。

## 卡片规范
- 视频卡片：宽 148dp、比例 3:4、圆角 `SquircleShape(Spacing.corner)`（16dp 连续曲率角）
  - 148dp 仅适用于首页网格；跨站源搜索结果卡宽度自适应（手机固定 2 列，宽 > 640dp 时 `GridCells.Adaptive(160dp)`），比例同样为 3:4
- 卡片标题行内边距：左右 `Spacing.posterTitlePaddingH`（10dp）、上下 `Spacing.posterTitlePaddingV`（6dp）
- 评分角标：`labelSmall`，水平 6dp / 垂直 2dp 内边距，50% 圆角，外边距 `Spacing.posterOverlayMargin`（8dp）
- 网格列数由 `videoGridColumns(homeLayoutSize)` 决定，禁止页面内写死列数
- 任何叠加视觉效果（淡入、扫光等）只能挂在绘制层（`Modifier.alpha` / `graphicsLayer`），不得改变卡片的尺寸、位置、间距
- 追番更新页卡片：每个板块（今日更新 / 待看更新）整体一张 miuix Card，标题在卡片内；卡片内左右 16dp、上下 8dp（条目之间 16dp、无分隔线，连体列表），条目按压只显示蒙层、不缩放；板块卡片之间用 `Spacing.sectionSpacing`（20dp）；海报与预览小图圆角统一为 `Spacing.updateCardCorner`（10dp）

## 颜色规范
- 主题色由 `Theme.kt` 的 `TvPlayTheme(themeColor)` 驱动：`themeColor` 为 0 时用品牌默认色（浅色 `BrandBlue` / 深色 `BrandBlueDeep`），非 0 时按种子色派生 `seedLightScheme` / `seedDarkScheme`。
- 页面必须通过语义色取色：`MaterialTheme.colorScheme.primary`、`background`、`onBackground`、`onSurfaceVariant`，**禁止直接把 `Brand*` 常量当作主题色使用**。
  - 例外：播放器全屏深色场景（控制层、选集栏、弹窗）允许使用 `Color.White` / `Color.Black` 与 `BrandBlueDeep` 作为文字色和选中态颜色；海报上的标题与角标固定白字同样不受此限。
- 背景色：`MaterialTheme.colorScheme.background`
- 文字色：`MaterialTheme.colorScheme.onBackground`
- 次文字：`MaterialTheme.colorScheme.onSurfaceVariant`

## 按钮规范
- 圆形按钮：48dp 直径
- 按压效果：tvCardEffect（focusedScale 1.08~1.12）
- 按压蒙层：pressEffect = true（默认）

## 组件选型规范

- 所有界面 UI 优先使用 miuix 自带组件（`top.yukonga.miuix.kmp.*`），不要自行重新设计。
- miuix 已提供的能力（滑杆、弹窗、卡片、输入框、列表项、开关等）直接调用，仅在 miuix 确实缺失时才自绘。
- 自定义组件需保持与 miuix 一致的视觉与交互，避免出现两套风格。

## miuix 常用组件速查（对应 0.9.x，细节以项目锁定的 0.9.4 源码为准）

> 摘录自官方中文文档，仅记录最常用参数与关键约束；完整参数以文档页为准。

### 布局与容器
- **Scaffold**（components/scaffold）：页面脚手架，参数 `topBar/bottomBar/floatingActionButton/snackbarHost/popupHost/content(paddingValues)`。**所有 Overlay 弹窗必须包在 Scaffold 内**，`popupHost` 默认 `MiuixPopupHost()`；内容区须自行消费 `paddingValues`。
- **TopAppBar / SmallTopAppBar**（components/topappbar）：`title/largeTitle(缺省=title)/navigationIcon/actions/scrollBehavior`；navigationIcon 与 actions **不含内置水平边距**，需手动加 `padding(start/end = 16.dp)`；默认水平边距 26dp、折叠高 56dp。
- **Card**（components/card）：`cornerRadius`（默认 16dp）、`insideMargin`（默认 0）、`colors`；交互模式用 `pressFeedbackType(Sink/Tilt)` + `showIndication` + `onClick/onLongPress`（仅交互式重载可用）。
- **BasicComponent**（components/basiccomponent）：列表/设置项基座，`title/summary/startAction/endActions/bottomAction/insideMargin(默认16dp)/onClick/enabled`，另有 content 槽自定义重载。

### 交互与输入
- **Button / TextButton**（components/button）：主要按钮配色用 `ButtonDefaults.buttonColorsPrimary()`；默认 MinWidth 58dp / MinHeight 40dp / 圆角 16dp。
- **IconButton**（components/iconbutton）：`onClick/enabled/holdDownState/backgroundColor`；`holdDownState` 用于弹窗弹出时保持按下视觉；默认 40×40dp 圆形。
- **TextField**（components/textfield）：`value/onValueChange/label/useLabelAsPlaceholder/leadingIcon/trailingIcon`，另有 `TextFieldState` 重载；默认圆角 16dp、内边距 16dp。
- **Switch**（components/switch）：`checked/onCheckedChange/colors(SwitchDefaults.switchColors())`，默认即 HyperOS 动画。
- **Slider**（components/slider）：`value/valueRange/steps/onValueChangeFinished/keyPoints/showKeyPoints/magnetThreshold(默认0.02)/hapticEffect(默认Edge，可None/Step)`；另有 VerticalSlider / RangeSlider。
- **TabRow**（components/tabrow）：`tabs/selectedTabIndex/onTabSelected`，可与 HorizontalPager 联动；标准高 42dp 圆角 12dp（Contour 变体 45dp / 8dp）。
- **SearchBar**（components/searchbar）：`SearchBar(inputField={ InputField(...) }, expanded, onExpandedChange){结果内容}`；InputField 默认前放大镜、后清除图标。
- **PullToRefresh**（components/pulltorefresh）：状态提升 `isRefreshing/onRefresh/pullToRefreshState`，`refreshTexts` 可传中文文案；**仅适用触控**，刷新逻辑不要写进 state。
- **Snackbar**（components/snackbar）：miuix 自实现（非 Material），`SnackbarHostState.showSnackbar(message, actionLabel, withDismissAction, duration)`，配合 Scaffold 的 `snackbarHost`。
- **ProgressIndicator**（components/progressindicator）：Linear / Circular / Infinite 三种；`progress = null` 即不确定态。
- **Badge**（components/badge）：`BadgedBox(badge={ Badge(){...} }){锚点}`；无内容为小圆点 6dp，带内容 16dp；默认 error 色。

### 弹窗（均需 Scaffold 包裹，经 MiuixPopupHost 渲染；0.9.x 用 `renderInRootScaffold`（默认 true），`onDismissFinished` 在关闭动画结束后回调）
- **OverlayDialog**（components/overlaydialog）：`show/title/summary/onDismissRequest/enableWindowDim/maxWidth/largeScreen/cornerRadius`；大屏居中缩放、小屏底部滑入，可用 `largeScreen` 强制；内容区自行放按钮行。
- **OverlayListPopup**（components/overlaylistpopup）：`show/alignment(6向)/enableWindowDim/minWidth/maxHeight`；内容用 `ListPopupColumn { DropdownImpl(text, optionSize, isSelected, index, onSelectedIndexChange) }`。
- **OverlayDropdownPreference**（components/overlaydropdownpreference）：设置项样式下拉，`title/summary/items/selectedIndex/onSelectedIndexChange/showValue(默认true)/enabled`；`DropdownEntry` 支持禁用项、图标、摘要、多选；分组重载中 `collapseOnSelection` 默认 `entries.size <= 1`（单组选中即收起）。

### 颜色选择
- **ColorPalette / ColorPicker**（components/colorpalette、colorpicker）：均受控 `color + onColorChanged`；Palette 为 HSV 网格盘（`rows/hueColumns/includeGrayColumn/showPreview`，内置透明度滑条不可关）；Picker 为滑条式，`colorSpace` 支持 HSV/OKHSV/OKLAB/OKLCH，各通道滑块可独立使用。

## 震动反馈规范

- 震动一律使用系统触感反馈：Compose 中用 `LocalHapticFeedback.current.performHapticFeedback(...)`。
- 不要自行创建 `Vibrator` 定制震动时长、振幅或波形，也不为此申请 `VIBRATE` 权限。
- 仅在明确的交互节点触发（如滑杆抵达吸附点），且避免连续重复触发。

## 圆角规范

### 圆矩形（统一 16dp = Spacing.corner）
所有圆矩形组件/按钮统一用 `Spacing.corner = 16dp`，不要写硬编码 dp 值。

| 组件 | 圆角 |
|------|------|
| 视频卡片 | 16dp（Spacing.corner） |
| 设置项卡片 | 16dp（Spacing.corner） |
| 搜索结果卡片 | 16dp（Spacing.corner） |
| 弹窗容器 | 16dp（Spacing.corner） |
| 弹窗选项按钮 | 16dp（Spacing.corner） |
| 错误页 | 16dp（Spacing.corner） |

### 胶囊形（统一用完美胶囊）
所有胶囊形组件必须用 `RoundedCornerShape(percent = 50)`，不要单独写圆角 dp 值。

| 组件 | 圆角 |
|------|------|
| 海报 badge（更新至HD/第X集） | percent = 50 |
| 站源 chip | percent = 50 |
| 搜索栏容器 | percent = 50 |
| 圆形按钮 | percent = 50 |
| 底栏胶囊 | percent = 50 |
