# UI 规范

## 间距基准

### 页面边距
| 名称 | 值 | 说明 |
|------|-----|------|
| 页面左右边距 | 16dp | 所有页面统一 |
| 顶部状态栏 | 系统自动处理 | WindowInsets.statusBars |
| 顶栏顶部间距 | 14dp | pageTop |
| 底栏内边距 | 系统自动处理 | |

### 组件间距
| 名称 | 值 |
|------|-----|
| 卡片水平间距 | 8dp |
| 卡片垂直间距 | 12dp |
| 列表项间距 | 6dp |
| 按钮间距 | 12dp |

## 顶栏规范

### 二级页顶栏（设置/收藏/历史/主题色板）
- 高度：48dp
- 标题：居中，titleLarge，SemiBold
- 返回键：左侧对齐 16dp，48dp 圆形按钮
- 背景：毛玻璃（BlurredBar）

### 首页顶栏
- 搜索栏：48dp 高，居中
- 分类 Tab：固定在搜索栏下方
- 毛玻璃效果

## 底栏规范
- 胶囊形，悬浮在底部
- 三个 tab：首页 / 收藏 / 设置
- 毛玻璃效果（与液态玻璃互斥）

## 字号规范
| 用途 | 字号 | 字重 |
|------|------|------|
| 页面大标题 | titleLarge (~22sp) | SemiBold |
| 卡片标题 | bodyLarge | Medium |
| 辅助文字 | bodyMedium | Regular |
| 小标签 | labelMedium | Regular |

## 颜色规范
- 主色：BrandBlue（品牌蓝）
- 背景色：MaterialTheme.colorScheme.background
- 文字色：MaterialTheme.colorScheme.onBackground
- 次文字：MaterialTheme.colorScheme.onSurfaceVariant

## 按钮规范
- 圆形按钮：48dp 直径
- 按压效果：tvCardEffect（focusedScale 1.08~1.12）
- 按压蒙层：pressEffect = true（默认）

## 组件选型规范

- 所有界面 UI 优先使用 miuix 自带组件（`top.yukonga.miuix.kmp.*`），不要自行重新设计。
- miuix 已提供的能力（滑杆、弹窗、卡片、输入框、列表项、开关等）直接调用，仅在 miuix 确实缺失时才自绘。
- 自定义组件需保持与 miuix 一致的视觉与交互，避免出现两套风格。

## 震动反馈规范

- 震动一律使用系统触感反馈：Compose 中用 `LocalHapticFeedback.current.performHapticFeedback(...)`。
- 不要自行创建 `Vibrator` 定制震动时长、振幅或波形，也不为此申请 `VIBRATE` 权限。
- 仅在明确的交互节点触发（如滑杆抵达吸附点），且避免连续重复触发。

## 圆角规范

### 圆矩形（统一 16dp = Spacing.corner）
所有圆矩形组件/按钮统一用 `Spacing.corner = 16dp`，不要写硬编码 dp 值。

| 组件 | 圆角 |
|------|------|
| 视频卡片 | 16dp（Spacing.corner） |
| 设置项卡片 | 16dp（Spacing.corner） |
| 搜索结果卡片 | 16dp（Spacing.corner） |
| 弹窗容器 | 16dp（Spacing.corner） |
| 弹窗选项按钮 | 16dp（Spacing.corner） |
| 错误页 | 16dp（Spacing.corner） |

### 胶囊形（统一用完美胶囊）
所有胶囊形组件必须用 `RoundedCornerShape(percent = 50)`，不要单独写圆角 dp 值。

| 组件 | 圆角 |
|------|------|
| 海报 badge（更新至HD/第X集） | percent = 50 |
| 站源 chip | percent = 50 |
| 搜索栏容器 | percent = 50 |
| 圆形按钮 | percent = 50 |
| 底栏胶囊 | percent = 50 |
