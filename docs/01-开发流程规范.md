# ICAN影视 开发流程规范

## 基本信息
- **包名**：com.ican.tvplay
- **项目根目录**：D:\new tvbox
- **编译命令**：`.\gradlew.bat :app:assembleDebug --console=plain -q`
- **APK 输出**：`app/build/outputs/apk/debug/app-debug.apk`
- **adb 路径**：`C:\Users\15791\AppData\Local\Android\Sdk\platform-tools\adb.exe`
- **设备序列号**：f2fd56d0

## 标准开发流程

### 1. 修改代码
- 直接在 Android Studio / Trae 中修改源文件
- 遵循现有代码风格（Compose + Miuix 组件库）

### 2. 编译 Debug 包
```powershell
cd D:\new tvbox
.\gradlew.bat :app:assembleDebug --console=plain -q
```

### 3. 推送到手机
```powershell
& "C:\Users\15791\AppData\Local\Android\Sdk\platform-tools\adb.exe" push "D:\new tvbox\app\build\outputs\apk\debug\app-debug.apk" /sdcard/Download/
```

### 4. 手机上安装验收
- 文件管理 → Download → app-debug.apk → 安装
- 验收功能是否正常

### 5. Git 提交
```powershell
git add <修改的文件>
git commit -m "类型: 简要描述"
```

## 常见操作

### 查看设备连接
```powershell
& "C:\Users\15791\AppData\Local\Android\Sdk\platform-tools\adb.exe" devices
```

### 查看最近 commit
```powershell
git log --oneline -5
```

### 查看未提交改动
```powershell
git status --short
```

## 注意事项
- 修改 UI 后必须重新编译 + 推送 + 安装才能看到效果
- 不要直接在手机上覆盖安装有签名冲突的包
- commit 信息要简明扼要，说明做了什么改动
