落地口径
1. PosterCaption 是首页 / 收藏 / 历史 / 跨站源搜索共用的组件，不能直接改死结构 —— 给它加一个可选参数 progress: Float? = null（0..1），只有历史卡传值；默认 null 时一个像素都不多画，其余页面零影响。
2. 顺序固定为：标题 → 4dp → 进度条（fillMaxWidth 吃满 12dp 内边距后的宽度，即与标题同宽）→ 4dp → 集数。
3. 条高 4dp 不变，新增 2dp 圆角；底 0x44FFFFFF、进度色 primary 保持不变。
4. 删掉历史卡原来那条 align(BottomCenter) 的通栏进度条（CollectionScreens.kt 约 671-685 行），以及那句“贴海报最底、通栏”的 KDoc。
5. 间距收口成常量 Spacing.posterProgressInlineGap = 4.dp、posterProgressInlineHeight = 4.dp、posterProgressInlineCorner = 2.dp，不要散落硬编码。
6. 无副标题（episodeTitle 为空）时，进度条下面直接接 10dp 底边距，不会塌。
7. 顺带：Spacing.historyProgressBarGap（10dp）自 11-22 改版后已无引用，这轮一并清掉。
